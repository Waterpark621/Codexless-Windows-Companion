# Local transaction substrate

InstallTransaction.psm1 implements local, bounded inventory staging and a destination-local sanitized incomplete-install fence. Each mutating boundary is journaled before its adapter operation. Atomic journal replacement retains previous sanitized versions. A per-root Windows mutex refuses concurrent transaction callers. Exact owner/root/payload digests bind receipts to the destination and immutable generation. Unknown roots and existing tasks are refused.

Repair only restarts an intact, independently verified owned generation; it cannot overwrite damaged or foreign material. Uninstall requires verified stop and exact task ownership, then removes listed unchanged payload files without recursive deletion. Unknown root/project data is preserved. Failed or interrupted operations retain the fence and refuse ordinary operation. A verified uninstall tombstone permits reinstall into the same retained root with a new generation.

This is an internal transaction engine with `NativeTransactionAdapter.psm1` as its real Windows authority adapter. The adapter accepts only caller-supplied externally trusted payload tree digests, verifies the transaction fence before irreversible task/runtime mutation, creates destination-local settings and optional current-user DPAPI credential state, and binds the exact transaction/generation into the Scheduled Task description and action. Task identity requires InteractiveToken, LeastPrivilege, `AllowHardTerminate=false`, the exact action/working directory, and the existing Scheduler ancestry/runtime ownership proofs. Foreign tasks or ambiguous mutable state are refused; stop remains cooperative and no foreign listener/process/runtime is adopted. A test-only task-name override is restricted to disposable `Codexless-NativeAdapter-Test-*` names.

For Codexless, callers must first use `Stage-QualifiedCodexlessDistribution` and pass only its returned `stagedRoot` into the native install transaction; the adapter's `VerifyStage` boundary can call `Assert-CodexlessDistributionRoot` to re-verify the copied generation. While the Codexless distribution slot is unpublished, non-plan `Install.ps1` calls `Get-ArtifactPolicy codexless` before destination mutation and fails closed. The adapter does not choose or weaken public artifact URLs or checksums. No friend-install readiness is claimed.

Update stages and verifies a fresh immutable candidate generation before exact current stop. It retains and re-verifies the previous payload and ownership record, promotes only through the task authority adapter, and requires exact candidate readiness. A failed candidate must be proven stopped before restoring the exact prior generation. Changed task authority, missing/changed rollback material or unproven exit retains both generations and the incomplete fence. Rollback itself must pass readiness before reporting rolled-back.

Real disposable process-exit tests interrupt each forward install/update journal boundary and confirm ordinary operations remain fenced. Cross-process Windows mutex contention is tested with a cooperative fixture worker. A separate disposable native test registers a uniquely named transaction-bound Scheduled Task, verifies the exported least-privilege identity and Scheduler ancestry, starts it, cooperatively stops it, and removes only that exact task. These tests do not constitute a different-user/machine acceptance test.
